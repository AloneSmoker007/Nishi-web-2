# AI artwork assets

The generated Purple Universe artwork is original decorative fantasy scenery, not a depiction of BTS members.

Add the optimised WebP files from the supplied artwork pack here:
- `purple-castle-hero.webp` — wide hero background
- `moonlit-castle-detail.webp` — castle detail card
- `rose-garden-terrace.webp` — rose garden / memory card

Then change `artwork.hero` in `content/site-config.js` to `assets/ai/purple-castle-hero.webp`.
The other two paths are already configured for future cards. Keep the existing SVG fallback until the WebP files are committed.
